| `amap-reference.json` | 高德步行路径参照数据 | 10 个候选地标的距离与坐标；含 BD-09 / GCJ-02 / WGS-84 三套坐标 |

## 复现本仓库报告中的验证结论

1. 读取 `track-guangzhou-20261016.gpx`（WGS-84）
2. 做坐标转换 **WGS-84 → GCJ-02 → BD-09**（本地区两者相差约 500 m，不转换会完全错位）
3. 调用 `GET /api/audit?lat=23.458320&lng=113.502141` 取得等时圈（BD-09）
4. 对每个轨迹点：设其在录制开始后第 T 秒被走到，则它必须落在 T 分钟等时圈内
5. 统计越界点数

**结果**：2417 点，越界 0 点，越界率 0.00%。

详见 [真实对比测试报告](../真实对比测试报告.md)。

## ⚠️ 使用限制（已在报告中如实声明）

本次实测最远仅 345 m，**未触及 15 分钟圈**（边界半径 177~825 m）。
因此该数据**只能证明「等时圈没有画小」，不能证明「没有画大」**——
包含性检验是单侧的。

另：`amap-reference.json` 中高德返回的「用时」经验算恒等于 `距离 ÷ 1.25`
（10 个点比值均为 0.799~0.800），是按固定步速换算的，**不含路况信息**。
因此它只能作为独立的**距离**参照，不能作为第二组时间测量。
