# 04 · 服务盲区识别算法

> 交付物对应：任务书「服务盲区识别算法」
> 任务书原文要求：**「能准确识别出周边 1 公里内没有菜市场、药店或小学的『服务盲区』点位」**，
> 且**「盲区判定应基于步行耗时而非直线距离」**。
> 事实来源：[docs/SOLUTION.md](../SOLUTION.md) §4.4、附录 C.3、C.4

---

## 1. 判定定义

> 点 `p` 对类别 `c` 是盲区 ⟺ 从 `p` 步行到最近一个类别 `c` 设施的**最短步行距离 > 1000 m**。
> 等价时长阈值 ≈ **750 s**（按 1.25 m/s 折算，**可配置**）。

**问题本质**：这本质上是「**耗时场下的 Voronoi 分配**」——

```text
BS = { g ∈ G :  t(g, NearestFacility(g)) > T }
NearestFacility(g) = argmin_f  t(g, f)        # 即耗时场 Voronoi
```

盲区就是那些「到最近设施的耗时超过阈值」的格网。这个等价关系是后面两套加速方案的理论基础。

**关键类别**：任务书点名的三类 —— **菜市场 / 药店 / 小学**。
三类盲区的**交集** = 「同时缺失」的**严重盲区**（最高优先级，也是报告里最该被放大展示的结论）。

---

## 2. 三套可行方案与配额权衡

| 方案 | 做法 | 算路消耗 | 精度 | 适用 |
| --- | --- | --- | --- | --- |
| **S1 设施侧等时圈并集（出结论）** | 对每个设施做一次阈值等时圈，覆盖区 = `∪ Iso(f)`，盲区 = 研究区 − 覆盖区 | 432 路线/设施（15 min）<br>约 **180 路线/设施**（1 km，5 环 × 36） | 高（IoU 0.93~0.96，见 [02-isochrone.md](02-isochrone.md)） | 设施数 ≤ 20 时直接出结论 |
| S2 网格点 → 最近设施 | 每个格心到 k 个最近设施批量算路 | 网格数 × k，**配额不可行** | 最高 | **仅作抽样验证** |
| **S3 解析场 + Voronoi 预筛 + 边界带精算（主方案）** | 解析模型估 `t̂` → 加性加权 Voronoi 分配最近设施 → 只对 `abs(t̂ − T) < δ` 的边界带用真实算路校正 | **只精算 5%~15% 的网格** | 中高 | 大范围快速普查 |

**主算法 = S3 预筛 + S1 出结论。**

为什么必须这样组合：纯 S2 的配额不可行；纯 S1 在设施多时会顶到 5,000 路线/日的上限；
而 S3 把「哪里需要真值」这件事**先算清楚**，只把配额花在等值线零交叉附近——这是本项目的省配额核心技巧。

---

## 3. 主算法流程

```text
输入：15 分钟等时圈多边形 A、关键类别 c 的设施集合 F_c
  │
  ├─ ① 解析耗时场（零配额）
  │     t̂(x) = u · d_euclid(x, f) / v + τ_cross
  │     作用在 100 m 网格上；u = 绕行系数（1.25 老城 / 1.35 一般城区 / 1.5 郊区）
  │
  ├─ ② 加性加权 Voronoi 分配（零配额）
  │     argmin_f t̂(x, f)  →  每个格网知道自己「最近的是哪个设施」
  │     设施规模差异用虚拟源距离偏移近似：c_f = −λ · log(供给量)  → 大设施势力范围更大
  │
  ├─ ③ 圈出不确定带
  │     margin(g) = t̂₂(g) − t̂₁(g)                # 最近与次近设施的耗时差
  │     B = { g : |t̂₁(g) − T| < δ 或 margin(g) < δ },  δ = 20% · T
  │
  ├─ ④ 边界带四叉树加密 + 真实算路校正（消耗配额，但只在一小片）
  │     100 m → 50 m → 25 m 细分，只对 B 内格心批量算路（1 起点 × 50 终点打包）
  │     用真实耗时替换解析估值，重新提取等值线
  │
  ├─ ⑤ 关键类别用 S1 出结论
  │     对 A 内 {菜市场, 药店, 小学} 的设施各做一次【1 km 阈值】等时圈 → 取并集得覆盖区
  │     盲区 = A − ∪ Iso(f)
  │
  ├─ ⑥ 盲区连通域聚合
  │     盲区格网 buffer(120 m) → unary_union → 多边形，按面积排序
  │     面积 < 0.01 km² 的碎块：合并到邻近或丢弃（可配置）
  │
  └─ ⑦ 综合盲区 = 三类盲区【交集】（严重盲区，最高优先级）
输出：盲区多边形列表 + 每块 { 面积, 缺失类别, 采样点, geometry }（对齐 CONTRACT.md §4 blindspots）
```

## 4. 各步骤的设计理由与依据

### 4.1 解析耗时场（①）

`t̂(x) = u · d_euclid / v + τ_cross`，参数取值与文献依据：

| 参数 | 取值 | 来源 |
| --- | --- | --- |
| 绕行系数 `u` | **1.25**（老城高密度网格）/ **1.35**（一般城区，默认）/ **1.5**（郊区、封闭式小区、河网分割区） | Marti & Weidmann 2016 综述步行 **1.2–1.5**，瑞士社区实测均值 **1.24–1.39**；Boscoe et al. 2012 实测美国驾车 detour index = **1.417**（r² = 0.94）；Cole & King 1968 英国乡村 1.2–1.6 |
| 距离衰减形式 | `u(d) = 1 + a·d^(−b)`（初值 a≈0.35、b≈0.5，d 单位 km） | Giacomin & Levinson 2015「短途更绕」 |
| 过街惩罚 `τ_cross` | 典型 **15–40 s**，长周期主干道 40–60 s | HCM 行人延误 `d_p = 0.5·C·(1 − g/C)²`；ATRF 2025 实测信号过街使步行时间 +2.5%~12.2% |
| 步行速度 `v` | **1.25 m/s**（4.5 km/h）；适老 / 儿童 1.0–1.1 m/s | 与等时圈采样保持同一常数 |

> **零成本标定（本项目的「免费午餐」）**：批量算路的 `ret_straight_dist=1` 能在**同一次配额内同时返回直线距离**，
> 于是可以抽 300~500 个 O-D 对做 Huber 稳健回归 `d_net = u · d_straight + ε`，**按距离分箱估 `u(d)`**，
> 再按方位角、是否跨河/跨铁路分组估屏障项，最后输出 `u` 的 95% CI 与残差 MAPE。
> **残差 MAPE ≤ 10% 即足以支撑盲区预筛**。这份标定结果本身就是报告里的硬核内容。
> 当前状态：**待验证**（依赖批量算路可用）。

### 4.2 加性加权 Voronoi（②）

因为 `t̂(x, f) = u·‖x − f‖/v + τ(‖x − f‖)` 对 `‖x − f‖` **单调**，
所以「按耗时分配最近设施」**等价于按加权距离划分**——这就是加性加权 Voronoi（additively weighted Voronoi）。

**实现**：numpy 全网格 `argmin`（1000 格 × |F| 次算术，**秒级完成，零配额**）。
设施规模差异用**虚拟源距离偏移**近似（给每个源一个初始代价 `c_f = −λ·log(供给量)`），让大设施势力范围更大——
这是对**容量差异**的低成本近似（严格的容量约束需要 2SFCA，见 §7）。

### 4.3 不确定带与四叉树加密（③④）

- `δ = 20% · T` 同时圈住**离阈值近的**格网和**两设施势力范围接近（margin 小）**的格网；
- 对 `B` 内格心做 **1 起点 × 50 终点**的批量算路打包；
- **只精算 5%~15% 的网格**。这正是「只在 marching squares 零交叉附近加密」的省配额技巧。

### 4.4 为什么最终结论一定回到 S1（⑤）

S3 的解析场再准，也是**模型**。任务书要的是「周边 1 公里内没有菜市场、药店或小学」——
这种结论一旦报错（把有设施的网格标成盲区），是**要被抓出来的硬错误**。
所以最终结论必须由**设施侧的真实等时圈并集**给出：

- `覆盖区 = ∪ Iso(f)`，`盲区 = 研究区 − 覆盖区`；
- **预算控制**：用 **1 km 阈值**而不是 15 分钟——半径更小 ⇒ 约 **5 环 × 36 = 180 路线/设施**。
  10 个设施 ≈ 1,800 路线，安全落在 5,000/日 内；
  若用 15 分钟（**432 路线/设施**），10 个设施 = 4,320 路线，**逼近上限**。
- **配额复用技巧**：
  ① 给中心点做的 432 点采样中，若某设施恰在采样点附近，可直接复用；
  ② 更重要的是——**先用 S3 的解析场筛出「最可能产生盲区」的 3~5 个设施再做精算**，而不是全量做。

### 4.5 连通域聚合（⑥）

盲区格网 `buffer(120 m)` → `unary_union` → 多边形；按面积排序；
面积 < **0.01 km²** 的碎块合并到邻近或丢弃（阈值可配置）。
`buffer(120 m)` 的作用是把 25~100 m 栅格的锯齿状边缘**圆滑成人类可读的斑块**，而不是一堆碎多边形。

## 5. 输出契约（对齐 CONTRACT.md §4）

```jsonc
"blindspots": {
  "total_area_m2": 123456.0,
  "polygons": [
    { "area_m2": 45678.0,
      "missing": ["market", "pharmacy"],
      "sample_point": { "lat": 31.21, "lng": 121.61 },
      "geometry": { "type": "Polygon", "coordinates": [[[121.61,31.21], ...]] } }
  ]
}
```

- `missing` 用的是**机器名**（`market` / `pharmacy` / `primary_school` …），与 `facilities.categories[].key` 同一套；
- `sample_point` 是该斑块内**最严重**（离最近设施最远）的点，前端点选清单时 `flyTo` 用它；
- `total_area_m2` 是**所有斑块面积之和**（不是并集面积的重算，避免自交导致的口径混乱）。

## 6. 补充产出：从「有设施」升级到「够不够用」

### 6.1 覆盖人口与公平性（比面积占比更有说服力）

把 WorldPop / 建筑轮廓人口栅格与覆盖区叠加 → **「15 min 步行覆盖人口比例」**。
政策语言是「多少人能走到」，不是「多少平方公里被覆盖」——**覆盖人口比覆盖面积更容易被评委理解**。

### 6.2 两步移动搜索法 2SFCA（可选）

若考虑多设施竞争与容量：

```text
R_j = S_j / Σ_k D_k f(d_kj)        # 第一步：每个设施的供需比
A_i = Σ_j R_j f(d_ij)              # 第二步：每个需求点的可达性
```

来源：Luo & Wang 2003；Luo & Qi 2009（Health & Place）。

### 6.3 补点建议：MCLP 最大覆盖选址（「规划助手」的关键差异化，**零配额**）

```text
max Σ w_i · y_i
s.t.  y_i ≤ Σ_{j : d(i,j) ≤ 1 km} x_j      # 每个需求点被至少一个选中设施覆盖
      Σ x_j ≤ K                            # 最多选 K 个（K = 1~3）
```

- 用**贪心 + 惰性加速（lazy greedy）**求解（子模性保证 `1 − 1/e` 近似）；
- 输出 **Top-3 候选点位** + 每个点位的「新增覆盖网格数 / 覆盖面积 / 覆盖人口 / **边际增益**」；
- LLM 结合规范条文对候选点写**选址理由**（每条理由必须引用一个已计算指标）。

**输出契约**：`siting[]` 的 `{ lat, lng, reason, gains }`（`gains` 是 `{类别: 新增数量}` 的映射）。

> 这一步把产品从「体检」（发现问题）推到「诊疗」（给出方案），
> 正是赛题标题「智能体检与**规划助手**」的后半句。

## 7. 验证方案（对齐 SOLUTION §11 测试协议）

| 指标 | 定义 | 验收目标 | 可接受 |
| --- | --- | --- | --- |
| **盲区面积误差** | `|A_blind_ours − A_blind_ref| / A_blind_ref` | ≤ 8% | ≤ 15% |
| **盲区命中率** | 算法标出的盲区点，人工用百度地图 App 复核「1 km 内是否真无该类设施」的**准确率 / 召回率** | 准确率 ≥ 85% | ≥ 75% |

**必须避免「循环验证」陷阱**：如果「真值」也用同一套 `routematrix` 采样得到，那只是**自证一致**，
连百度 API 自身的系统偏差都测不出来。因此真值必须来自**独立源**（百度地图 App 步行导航人工记录为主，实地 GPS 轨迹校准速度与过街惩罚）。

## 8. 已知局限（诚实声明）

| # | 局限 | 影响 | 缓解 |
| --- | --- | --- | --- |
| 1 | 解析模型的 `u` / `τ_cross` **尚未在本项目数据上标定** | S3 预筛可能偏乐观或偏保守 | 用 `ret_straight_dist=1` 零成本标定（**待验证**）；S3 只做预筛，结论由 S1 出 |
| 2 | 屏障图层一期靠人工勾绘 | 跨河/跨铁路的盲区判定可能失真 | 屏障配置 JSON；二期接官方水系/绿地分类 POI |
| 3 | MCLP 的 `w_i`（需求权重）当前用**均匀权重** | 未体现人口分布差异 | 接人口栅格后改为人口加权（§6.1）；当前标注为**等权近似** |
| 4 | 盲区概率图（蒙特卡洛）为**设计预留**，未实现 | 二值结论而非概率结论 | SOLUTION §4.4 Step 8 已给出方法；时间允许时补 |
| 5 | 2SFCA 未实现 | 未考虑设施容量与竞争 | 当前用加性加权 Voronoi 的虚拟源偏移近似 |
